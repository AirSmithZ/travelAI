## 1. 架构现状

总览连线分 **三套渲染路径**：

| 类型 | 组件 | 数据 | 几何 |
|------|------|------|------|
| 单元格内主路线 | `OverviewBezierEdge` | `collectIntraCellEdgePlacements` | 卡片边框 + 贝塞尔 |
| 同天跨区 | `OverviewEdgeLayer` | `getCrossRegionEdges` + `computeOverviewAnchors` | 锚点 + 贝塞尔 |
| 单元格内备选 | `OverviewBezierEdge`（底栏） | `getIntraCellAlternativeEdges` | ~~硬编码水平线~~ → 已改为真实节点连接 |

单程 `ItineraryGraph` 统一用 `day.edges` + ReactFlow `TripEdge`，锚点在节点真实边界。

## 2. 问题清单（修复前）

### P0 · 跨区线被单元格遮挡

- `overview-edge-layer` z-index **1**，`overview-cell` z-index **2**
- 跨区竖线穿过中间区域行时被不透明格底盖住，**几乎不可见**

### P0 · 跨区锚点为卡片中心，与格内边框锚点不一致

- `computeOverviewAnchors` 仅存节点中心
- `getAnchorConnection` 从中心出发却标注 `bottom/top` 侧向 → 线穿入卡片内部
- 格内 `getNodeConnection` 使用边框中点，**同一行程两种连接语义**

### P1 · 备选路线为假几何

- 底栏 `x1={i*90+8}` 硬编码，不连任何节点
- 与单程「父节点 → 可选子节点」语义不符

### P1 · 拖拽时线与节点不同步

- 节点 `transform` 跟手，连线用静态 `edgePlacements`
- 拖拽过程中出现「线断、节点飞」

### P2 · 标签双轨

- 格内：`foreignObject` HTML 胶囊
- 跨区：SVG `<text>`
- 字号/对比度/图标渲染不一致

### P2 · 布局重复计算

- `computeOverviewAnchors` 内二次调用 `computeCellLayout`，与矩阵布局易漂移

### P3 · 视觉与图例

- 跨区线过淡、线型与图例「跨区」语义不完全对应
- 跨区边未区分 primary / alternative 层次

---

## 3. 修复方案（按优先级）

| 优先级 | 措施 | 关键改动 |
|--------|------|----------|
| P0 | 跨区线可见 | 跨区层 z-index 置于格底之上、节点之下；或分段绘制 |
| P0 | 边框锚点 | `computeOverviewAnchors` 从 `layout.cells` 推导边框连接点 |
| P1 | 备选边 | 用 `getNodeConnection` 连接真实节点对 |
| P1 | 拖拽同步 | 拖拽 preview 时重算边端点或同步 transform |
| P2 | 标签统一 | 跨区改用 `OverviewBezierEdge` 或共用标签组件 |
| P2 | 单布局源 | 锚点不再二次 `computeCellLayout` |

---

## 4. 修复后行为

- 矩阵分三层：`overview-matrix__backgrounds`（z-0）→ `OverviewEdgeLayer`（z-1）→ `overview-matrix__foreground`（z-2，节点 z-3）
- 跨区锚点：`computeOverviewMatrixPlacements` 从 `layout.cells` 推导边框盒，与格内共用 `getNodeConnection`
- 备选边：`altEdgePlacements` 连接真实节点对，移除底栏假横线
- 拖拽同步：`connectionBetweenPlacements` + `applyDragToPlacement`，格内/跨区边随 preview 偏移
- 跨区标签：复用 `OverviewBezierEdge`（`variant="region"`），与格内 HTML 胶囊一致

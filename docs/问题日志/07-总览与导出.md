### P121 · 总览导出白屏 / 卡死（2026-08-10）✅

**现象**：总览点「导出 PNG」后预览区变白，按钮停在「导出中…」，长行程（如 7 日密集团览）易卡死或标签页 OOM。

**根因**
1. OV-02 浅色主题与全尺寸撑开作用在**可视 DOM**上，用户眼前即「变白」
2. `pixelRatio: 2` × 关虚拟化全列 × `getFontEmbedCSS` 嵌入 Noto Sans SC → 主线程长时间阻塞 / 内存顶满
3. 无超时与错误提示，失败或挂起时无法感知恢复

**修复**
1. **屏显保持暗色总览**：导出态用暗色实色（`EXPORT_SHELL` / `REGION_EXPORT_*`），不再盖遮罩、不挪 DOM、不用浅色主题闪屏
2. **PNG 与屏显一致**：底色 `#070b10`；显式传入 `width`/`height`；自适应 `pixelRatio`；大图跳过字体嵌入
3. **截图 45s 超时** + 按钮错误态「导出失败，重试」
4. ~~离屏 park~~ / ~~veil 遮罩~~ 已废弃（分别导致 insertBefore 空屏 / 导出中整区空白）
5. **防纵向截断**：导出态解除 `flex:1` 压缩，`minHeight`/`scrollHeight` 按全内容高度捕获（否则 PNG 只剩视口条带）
6. **节点卡片实色导出**：`exportMode` inline 边框/背景/flex；关入场动画；系统 CJK 字体栈（大图不嵌 Google Font）

**涉及**：`exportGraphImage.ts`、`exportGraphCaptureLimits.ts`、`ExportGraphButton.tsx`、`OverviewGraphView.tsx`、`OverviewCellNote.tsx`  
**文档**：[总览图导出功能分析](./总览图导出功能分析.md) · [TODO-路线图与总览 OV-05](./TODO-路线图与总览.md)

### P84 · 松手后实线错位、滚动才对齐（2026-08-09）✅

**现象**：拖完节点后跨区实线端点有时对不准节点；一滚动总览又跳回正确位置。

**根因（交互一致性）**：`useOverviewNodeAnchors` 的 revision 原先只看「节点个数 / 天数 / 区域数」。松手写入 `overview_offset` 后 layout 坐标已变，但 revision 不变 → 不重新 `measure()`。`ResizeObserver` 只对尺寸变化敏感，**绝对定位的 left/top 移动不会触发**；滚动监听会 `measure()`，所以一滚就修好。期间 stale DOM 锚点仍覆盖正确的 `matrixPlacements`。

**修复**：`anchorRevision` 纳入各节点 `x/y` 指纹，拖拽提交后强制重测。

**验收**：跨区拖节点松手 → 实线立即贴边，无需滚动

### P83 · 总览拖拽跨区实线不同步（2026-08-09）✅

**现象**：拖节点时同格虚线跟手，跨区实线（如酒店↔餐厅）停在原点，交叉/卡顿感明显。

**根因**：跨区边走 `OverviewEdgeLayer`，OV-01 DOM 锚点量到的是原地 `ghost-source`，盖住了 `liveMatrixPlacements` 的幽灵坐标；同格边用 `edgeDragPreview` 增量，故虚线正常。

**修复**：拖拽中跳过活跃节点的 DOM 锚点覆盖；幽灵卡片不注册 `data-overview-node`。

**验收**：拖动跨区主链节点 → 实线端点跟幽灵（同格虚线行为不变）

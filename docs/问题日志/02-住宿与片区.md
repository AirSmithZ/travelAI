### P120 · 片区 lodging localStorage 缓存（2026-08-10）✅

**现象**：片区酒店仅有进程内内存缓存，刷新/重开后重复请求 SerpApi，易与 recommend geocode 叠加触发 429。

**实施方案**
1. **L2 持久化**：`localStorage['travel.lodging.search.v1']`（对齐 `evidenceLinkCache`）；内存作热路径镜像  
2. **Key**：`v1|lat4|lng4|radius|city`（**不含 zoneId**，重推荐同圆心仍命中）  
3. **只写成功有候选**；empty / 429 / provider_error 不写  
4. **TTL 12h**、最多 40 条 LRU；刷新页面不清除  
5. **读路径**：默认优先缓存；「重新检索」才绕过打网；429/失败时若有未过期缓存则降级展示并提示  
6. **UI**：缓存命中提示「缓存命中（…前）· 可重新检索」

**验收**：`npx tsx frontend/src/utils/lodgingSearchCache.test.ts`  
**主键**：`lodgingSearchCache.ts` · `ZoneAreaLodgingModule.tsx`

### P119 · lodging：坐标 reverse 取 EN 城 + SSL 瞬时重试（2026-08-09）✅

**现象**：`city=罗托鲁瓦` 圆心正确，仍 `status=provider_error`，`query=hotel 罗托鲁瓦`，warning 为 `[SSL: UNEXPECTED_EOF_WHILE_READING]`。

**根因**
1. 罗托鲁瓦不在 airports/aliases → 无 `city_en`，落到中文 `hotel 罗托鲁瓦`

- `city_en_from_coords`：Nominatim reverse（`addressdetails` + `accept-language=en`）解析 city/town（罗托鲁瓦→Rotorua），不写死城市表
- 有坐标时 query 仅 `hotels near {EN}` / `hotels`，**禁止**中文 fallback
- SSL/超时等瞬时错误与 429 一样退避重试 1 次，失败即停，不再试下一劣 q

**验收**：`PYTHONPATH=. python backend/scripts/test_lodging_search.py`  
**主键**：`lodging_search.py`

### P118 · 片区 lodging：EN query + 429 可感知（2026-08-09）✅

**现象**：片区圆心已在奥克兰/罗托鲁瓦，点「搜索片区酒店」仍空；UI 显示「片区附近暂无候选」。日志：`SerpApi 429` + `q=hotel+奥克兰市中心—Britomart+枢纽带`。

**根因**
1. recommend 后连续打 Maps，lodging 撞 **429**；失败被吞成 `[]`，与「附近无酒店」不可区分

- 同响应内半径放宽（tight → wide）增加候选；空/限流不入 lodging 缓存
- FE 抵达城 bias 改走 `/flights/airports`，去掉 `ARRIVAL_CITY_ZH` 硬编码

**验收**：`PYTHONPATH=. python backend/scripts/test_lodging_search.py`  
**主键**：`lodging_search.py` · `stay_zones.py` · `ZoneAreaLodgingModule.tsx` · `flightArrivalCity.ts`

### P106 · 选酒店时镜头对准片区但圈/钉不绘制（2026-08-09）✅

**现象**：住宿面板已展开候选（含 lat/lng），右侧地图对准乌节路一带，但无片区圈、无酒店圆点；角标仍像「单日地图」。

**根因**（非「酒店与行程图层未拆开」——P100 已分源）

4. 展开选酒店前不强制开预览，检索完成前只有列表

**修复**
- `whenMapStyleReady`：跟 `idle` / `styledata` 直到可写
- `updateStay*` 返回成功与否；仅成功时记 `fitKey`；resize 走完整 `syncMapData`
- 酒店钉补 `Noto Sans Regular`；无节点时 `bringStayHotelPinLayersToFront`
- 片区圈加深（琥珀描边）；展开选酒店即开地图；角标改为「住宿预览」

**主键**：`mapStylePatches.ts` · `stayZoneGeoJSON.ts` · `stayHotelMapPins.ts` · `TravelMap.tsx` · `StayZonePanel.tsx`

### P105 · 生成中 Activity 与「生成前检查」同屏（2026-08-09）✅

**现象**：点「生成玩法」后对话里同时出现「正在生成玩法」Activity 与「生成前检查」闸门（按钮「生成中…」），像两张卡叠在一起。

**根因**：`showReadiness` 与 `isGeneratingItinerary` / `chatActivity` 无互斥；checklist 保留了生成中 loading UI，与 UX-CHAT-05 进度气泡职责重复。

**修复**：生成中强制关闸门；`openReadiness` / footer 在 generate Activity 期间拒开；去掉 checklist「生成中…」分支，进度只由 Activity 承担。

**主键**：`ChatPanel.tsx` · `ReadinessChecklist.tsx`

### P103 · 无内容时「行程图」展开空右栏（2026-08-09）✅

**现象**：P97 后，计划摘要「行程图」/`open_preview` 仍可能把 `previewExpandedWithoutItinerary` 打开，右侧只剩 EmptyPreview 并挤压对话。

**根因**：展开只看标志位，不校验是否有片区 geometry / 酒店钉。

**修复**
- `selectPreviewCollapsed`：无行程时须有 geometry 或 `stayHotelMapPins` 才展开
- `PlanSummaryCard.openPreview`：无内容直接 return
- 收起选酒店且无片区时清展开标志

**主键**：`usePlanStore.ts` · `PlanSummaryCard.tsx` · `StayZonePanel.tsx`

### P98 · 已有行程仍显示「生成玩法」（2026-08-09）✅

**现象**：玩法已生成后「生成前检查」仍可点「生成玩法」，重复渲染；生成中摘要侧仍显示「检查并生成玩法」。

**根因**：`ReadinessChecklist` 只看 `canGenerate`；`showReadiness` 本地 state 不随 itinerary 关闭。

**修复**：有 `itinerary.days` 时自动关闭 checklist、CTA 改为「知道了」；`openReadiness` 直接拒绝；`PlanSummaryCard` 在生成中/已有行程时隐藏下一步生成入口。

**主键**：`ReadinessChecklist.tsx` · `ChatPanel.tsx` · `PlanSummaryCard.tsx` · `planReadiness.ts`

### P67–P77 · UX / 机酒 / 对话十一项（2026-08-09）✅

**来源**：用户反馈 + 截图（住宿片区「酒店名称」默认填片区名）+ skill 分析（ui-ux-pro-max / design-taste / ai-chat-ui）。

| ID | 现象 | 根因 | 修复要点 | 主键文件 |
|----|------|------|----------|----------|
| **P67** | 对话框各板块提示词过时/术语化 | 空态仍写「确认后自动生成」；住宿 hint 混用 lodging/OTA | 按 phase 改空态/composer；住宿文案口语化 | `ChatPanel.tsx`, `StayZonePanel.tsx` |
| **P68** | 未生成行程仍可点「路线预览」展开空壳 | strip 无门禁；展开仅 EmptyPreview | 无行程且无片区 geometry 时禁用 strip | `InputPanel.tsx`, `PreviewPane.tsx` |
| **P69** | 右上角旅行弹出框样式异常 | portal 宽度/阴影/裁切与 token 不一致 | 对齐 radius/边框/z-index/overflow | `PlanSelector.css` |
| **P70** | 航班空结果仍提示「缓存命中」 | 空 `ranked` 也 `cacheSet` | 仅缓存有报价结果；空结果不标缓存 | `FlightIntelPanel.tsx`, `searchResultCache` 用法 |
| **P71** | 对话提取反复审批 | 规划期 destination/日期等强制 FormPatch | 无行程时 trip_request 低风险自动写+Undo；有行程后改字段需确认 | `lowRiskPatches.ts`, `ChatPanel.tsx` |
| **P72** | 酒店「确认添加」无反馈 | 成功无 toast；无行程时静默 return | toast + 对话 ack；无行程明确提示 | `StayZonePanel.tsx`, `usePlanStore.addHotelFromZone` |
| **P73** | 航班常查不到票却体验不清 | Ignav 未配/失败时仅「未找到」；与缓存文案打架 | 区分无源/无报价；突出 Trip 深链与手动添加 | `FlightIntelPanel.tsx` |
| **P74** | 「在地图查看并编辑」无反应 | map 折叠左栏；无行程不渲染 TravelMap | form/选中节点时不折叠；有片区时渲染地图 | `usePlanStore.selectLeftPanelCollapsed`, `PreviewPane.tsx`, `StayZonePanel.tsx` |
| **P75** | 「酒店名称」默认是片区名，步骤歧义 | `` `${zone.label} 附近酒店` `` 预填 | 两步：片区→搜酒店；默认空；展开自动检索 | `StayZonePanel.tsx` |
| **P76** | 玩法印证像「只有提示词」且不明显 | 入口仅生成后；摘要偏软 | 摘要强化；生成前可打开说明；strip 可见 | `PlanSummaryCard`/`planReadiness`, `InputPanel`, `EvidencePanel` |
| **P77** | 开销面板找不到 | 仅节点编辑有开销字段，无行程级入口 | 顶栏左侧「开销」按钮 → 抽屉汇总 | `ExpensePanel.tsx`, `AppShell.tsx` |

### P115 · geocode 后可疑边自动补算 + Directions 缓存（2026-08-09）✅

**现象**：TRN-01 仅面板按需查询；生成/geocode 后远距离仍可能保留 walk/20，定稿前通勤不可信。

**方案（TRN-02）**
- geocode 完成后对**可疑 primary 边**自动 `lookup_commute`（最多 N 条，默认 8）
- Directions 结果进程内 TTL 缓存（默认 7 天）
- 已 `route_source=directions|user_hint` 跳过；提示词海路/山路仍可命中
- `geocode-nodes` 透传 `free_text`/`notes`；前端后台 geocode 带上 trip_request

**配置**：`COMMUTE_AUTO_ENRICH` · `COMMUTE_AUTO_MAX_EDGES` · `COMMUTE_CACHE_TTL_SEC` · `COMMUTE_SUSPICIOUS_*_M`  
**主键**：`commute/enrich.py` · `commute/cache.py` · `itinerary_llm._after_geocode_enrich` · `test_commute_enrich.py`  
**文档**：[04 §5.2](./llm-travel-data/04-通勤与交通卡.md)

### P114 · 按需通勤查询 + 提示词海路/山路兜底（2026-08-09）✅

**现象**：行程边 `transport_mode` / `duration_minutes` 多为 LLM 估或写死默认（walk/20、taxi/25）；地图直线连线；海路/山路等 Directions 常无结果，无法按用户描述落地。

**方案（TRN-01，控费）**
- **按需**而非 generate 全量查路：`EdgeEditor`「查询通勤」→ `POST /api/v1/commute/lookup`
- SerpApi `google_maps_directions`：按直线距离选 1–2 个 travel_mode
- 从 `free_text`/`notes` 抽取轮渡/山路/缆车等 **user_hint**；Directions 失败时仍可应用提示词路线
- 边增加 `route_source`：`directions` | `user_hint` | `estimate`

**主键**：`commute/` · `api/v1/commute.py` · `EdgeEditor.tsx` · `api/commute.ts` · `test_commute_lookup.py`  
**文档**：[04-通勤与交通卡.md](./llm-travel-data/04-通勤与交通卡.md) · llm TODO `TRN-01`

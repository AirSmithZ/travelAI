# 旅行细节 — 行前 Intel 补充清单

← [返回索引](./README.md) · 相关：[01-航班信息.md](./01-航班信息.md) · [02-酒店信息.md](./02-酒店信息.md)

> 分析日期：2026-06-30 · 文档版本：v1.2

以下模块建议作为 **行前 Intel**（`meta.pre_trip_checklist[]`），不全依赖 POI 级 `tips[]`。

---

## 1. 证件与入境

| 项目 | LLM + 数据源 |
|------|--------------|
| 签证 / 免签 / eVisa | 外交部 / 移民局 API 或结构化知识库 |
| 护照有效期、空白页 | 规则引擎 |
| 入境卡 / 海关申报（现金上限） | 国家별模板 |
| 国际驾照 / 当地驾照 | 自驾场景 |
| 过境签（第三国中转） | 与 [01-航班信息.md](./01-航班信息.md) 联动 |

---

## 2. 健康与安全

- 疫苗要求（黄热病等）、旅行保险（医疗、延误、行李）。
- 紧急号码（警察/急救/中国驻外使领馆）。
- 治安热点、自然灾害季、政治动荡（中国领事保护、英美 FCDO 等官方建议）。

---

## 3. 金钱与支付

- 当地货币、刷卡普及度、小费文化。
- 汇率与手续费（exchangerate.host、央行）。
- 退税（VAT/Tax Free）流程、最低消费、机场退税柜台。
- 预授权、动态货币转换（DCC）陷阱。

---

## 4. 通讯与数字化

- eSIM / 本地 SIM（Airalo 类 API 或静态套餐表）。
- 离线地图、翻译 App、打车 App（Grab/Bolt/Uber）。
- 电源插头与电压（Type A/C/G…）。

---

## 5. 时间与节奏

- 时区、夏令时（DST）切换日。
- 公共假日（商店闭店）— **Calendarific / Nager.Date API**。
- 营业时间文化（南欧 siesta、周日歇业）。

---

## 6. 行李与物品

- 航司行李额度（与航班模块联动）。
- 液体登机限制、充电宝 WH 上限。
- 气候对应衣物（与 `DayWeather` 联动；Phase 2 接 **和风天气**，见 [15 §1.3](./15-天气联网与决策Agent缺口分析.md)）。

---

## 7. 文化与礼仪

- 着装（宗教场所）、摄影限制、小费比例。
- 禁忌（手势、礼物、话题）。

---

## 8. 特殊人群

- **亲子**：推车友好、亲子房、儿童票规则。
- **无障碍**：轮椅、电梯（GTFS `facilities`）。
- **饮食**：清真、素食、过敏原（餐厅 `tags`）。

---

## 9. 变更与应急

- 航班延误/取消 → 后续节点自动后移建议。
- 酒店 no-show 政策。
- 备用日（rain plan）— 与 `weather.icon` 联动室内备选。

---

## 10. 落地路线

| 阶段 | 方案 |
|------|------|
| **Phase 1** | LLM 生成 checklist 草稿 + `confidence: low` |
| **Phase 2** | 新加坡/日/泰 YAML 知识库 + 节假日 API |
| **Phase 3** | Compliance Agent；与航班/酒店变更联动 |

**Schema 映射**：`meta.pre_trip_checklist[]`（P2）→ [00-概述与架构.md](./00-概述与架构.md)。

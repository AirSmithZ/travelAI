## 2. 总体架构建议

```
TripRequest + 对话上下文
  → 意图路由（Planner Agent）
      ├─ search_flights      → [01-航班信息.md](./01-航班信息.md)
      ├─ search_hotels       → [02-酒店信息.md](./02-酒店信息.md)
      ├─ search_activities   → [03-游玩项目.md](./03-游玩项目.md)
      ├─ route_transit       → [04-通勤与交通卡.md](./04-通勤与交通卡.md)
      ├─ fetch_travel_basics → [05-行前细节清单.md](./05-行前细节清单.md)
      └─ synthesize_itinerary → Itinerary JSON
  → resolve_place（已有 Geocoding）
  → Pydantic 校验 + warnings[] + meta.provenance
```

与现有实现对齐：

- 行程骨架仍输出 `Itinerary`（`days[].nodes[]`、`edges[]`）。
- **新增**可选子对象：`flight_quotes[]`、`hotel_quotes[]`、`activity_catalog[]`、`transit_cards[]`、`pre_trip_checklist[]`（嵌在 `meta` 或独立 `TravelIntel` 层）。

## 3. LLM 实现模式（结合 llm-api-engineering）

### 3.1 分层 Agent

| Agent | 工具 | 输出 | 专题 |
|-------|------|------|------|
| **Planner** | 路由、预算校验 | 任务 DAG | — |
| **Flight** | `search_flights` | `FlightQuote[]` | [01-航班信息.md](./01-航班信息.md) |
| **Hotel** | `search_hotels` | `HotelQuote[]` | [02-酒店信息.md](./02-酒店信息.md) |
| **Activity** | `search_activities` | 带 `ActivityDetail` 的节点 | [03-游玩项目.md](./03-游玩项目.md) |
| **Transit** | `route_transit`, `get_transit_card_guide` | 增强 `edges[]` | [04-通勤与交通卡.md](./04-通勤与交通卡.md) |
| **Compliance** | `get_visa_rules`, `get_holidays` | `pre_trip_checklist[]` | [05-行前细节清单.md](./05-行前细节清单.md) |
| **Synthesizer** | 无（仅组装） | `Itinerary` JSON | — |

### 3.2 数据可信度标记

```typescript
type DataProvenance = {
  source: 'api' | 'official_kb' | 'llm_estimate' | 'user';
  fetched_at?: string;
  confidence: 'high' | 'medium' | 'low';
  url?: string;
};
```

**规则**：

- `api` + `high` → 可展示为「参考价」。
- `llm_estimate` → 必须显示「估算，请以预订页为准」。
- 解析失败 → 422，**不静默降级**。

### 3.3 Prompt 要点

1. System：角色 + **禁止编造票价** + JSON Schema。
2. User：注入 `TripRequest`、已选报价 ID、预算上限。
3. 工具结果以 **结构化 JSON** 回灌，而非原始 HTML。
4. `supplement` 模式改酒店/航班时，重新触发对应 Agent。

### 3.4 性能与成本

- 航班 + 酒店 + 活动 **并行** `asyncio.gather`。
- 缓存：同 `(origin, dest, date, pax)` 报价缓存 15～30 分钟。
- 流式：先返回骨架 `days[]`，再 SSE 推送 `quotes` 补丁。

## 4. 与现有 Itinerary Schema 的映射

| 新 intel | 映射位置 | 优先级 |
|----------|----------|--------|
| 航班报价 | `cross_day_edges` + Day1 `airport` 节点 metadata | P0 |
| 酒店报价 | `hotel` 节点 `cost` + 备选 `is_optional` | P0 |
| 活动详情 | `attraction` / `landmark` 扩展 `activity_detail` | P1 |
| 通勤票价 | `edges[].fare_estimate` | P1 |
| 交通卡指南 | Day1 `transit` 节点或 `meta.transit_cards[]` | P1 |
| 行前清单 | `meta.pre_trip_checklist[]` | P2 |
| 数据来源 | `meta.provenance[]` | P0 |

**最小侵入方案** — 扩展 `ItineraryMeta`：

```typescript
interface ItineraryMeta {
  // existing...
  flight_quotes?: FlightQuote[];
  hotel_quotes?: HotelQuote[];
  transit_guides?: TransitCardGuide[];
  pre_trip_checklist?: Array<{ category: string; items: string[] }>;
  provenance?: DataProvenance[];
}
```

类型定义详见各专题文档。

当前 Schema 仅有粗粒度 `category: attraction | landmark | restaurant | snack`。境外智能规划需 **二级品类 + 票务模型**。

---

## 1. 品类矩阵

| 二级品类 | 典型示例 | 价格结构 | 关键注意事项 |
|----------|----------|----------|--------------|
| **门票景点** | 博物馆、主题乐园、观景台 | 成人/儿童/老人票；时段票 | 预约时段、闭馆日、背包规定 |
| **自然户外** | 国家公园、徒步线 | 入园费 / 免费 | 天气、装备、向导、闭园 |
| **演出赛事** | 音乐会、体育 | 座位分区 | 开票时间、实名、退改 |
| **体验课程** | 烹饪课、潜水 OW | 按人头 / 按组 | 最低人数、语言、证书 |
| **餐饮** | 米其林、大排档 | 人均 / 套餐 | 订位、着装、小费 |
| **购物** | 奥特莱斯、免税店 | 可变 | 退税门槛、营业日 |
| **宗教/礼仪场所** | 寺庙、清真寺 | 免费或捐赠 | 着装、摄影限制 |
| **夜间娱乐** | 酒吧、夜游 | 最低消费 | 年龄限制、安全 |

## 2. 推荐数据源

| 品类 | API / 平台 |
|------|------------|
| 门票体验 | **本项目不接** Partner（Viator / GYG / Klook / Tiqets）；保留 LLM `cost_label` / 估算 |
| 演出 | Ticketmaster、Eventbrite、当地官方（不排期） |
| 餐厅 | Google Places、SerpAPI Maps 价位、OpenTable、Tabelog（日）、Michelin Guide（静态） |
| 免费 POI | Wikidata、OpenStreetMap、官方旅游局开放数据 |

**落地边界**：门票 **不** 接 Partner API（~~Viator~~ 已取消，见 **COST-01** ❌）；餐饮/免费 POI 走 Places + LLM + 知识库（B 层），见 **COST-02**。

## 3. Schema 扩展

```typescript
interface ActivityDetail {
  sub_category: 'ticketed_attraction' | 'outdoor' | 'show' | 'experience' |
                'dining' | 'shopping' | 'religious' | 'nightlife';
  booking_required: boolean;
  booking_url?: string;
  opening_hours?: Record<string, string>; // mon-sun
  closed_dates?: string[];
  duration_typical_minutes?: number;
  price_tiers?: Array<{
    label: string;
    amount: number;
    currency: string;
    age_rule?: string;
  }>;
  restrictions?: string[];
  best_visit_window?: string;
}
```

**LLM 职责**：

- 按 `preference_tags` 做 **品类配额**（如每天 1 餐饮亮点 + 2 景点）。
- 冲突检测：闭馆日与 `date`、演出与 `start_time`。
- `tips[]` 首条 = 总览摘要，其余 = 分项注意事项。

**Schema 映射**：`attraction` / `landmark` 扩展 `activity_detail`（P1）→ [00-概述与架构.md](./00-概述与架构.md)。

## 5. 豆包对话 Trip.com 景点数据核验

**来源**：同 [02-酒店信息.md §5](./02-酒店信息.md#5-豆包对话-tripcom-数据源核验2026-06-30) 所引 [豆包对话](https://www.doubao.com/thread/x2b906885bbdb81ce91d412c004cdc7e9)

豆包称 Apify [Trip.com Scraper](https://apify.com/one-api/trip-com-scraper) 可搜 **things-to-do、POI 详情**。

| 说法 | 核验 | 结论 |
|------|------|------|
| 支持景点/玩乐搜索 | Actor README 含 Attractions search + POI detail | ✅ |

**本项目决策（2026-08-11）**：**不接入** Viator / Klook / GYG 等门票 Partner；Apify 景点爬虫亦不作生产依赖。门票开销维持 LLM 估算 + `cost_label`。

## 2. 本轮交付（2026-07-03）

### 2.1 中文地名

| 项 | 路径 |
|----|------|
| IATA → 中文 + 别名 → IATA | `frontend/src/data/airportLabels.ts` |
| 航线格式化 | `formatRouteLabel` / `formatLegRoute` in `flight.ts` |
| 经停常见码 | HAN、ICN、DMK、TPE 等已收录；未知 fallback IATA |

### 2.2 手动添加

| 项 | 路径 |
|----|------|
| 类型与合成 quote | `ManualFlightLegInput`、`flightLegFromManualInput` → `travelIntel.ts` |
| Store | `usePlanStore.addManualFlightLeg` |
| UI | `FlightManualAddPanel.tsx`（折叠区，嵌入 `FlightIntelPanel`） |
| 溯源 | `source: manual`；`booking_status: booked_external` 可选 |
| 摘要 | `formatFlightLegSummary` 含「已订·手动」/「参考价」 |

### 2.3 用户路径

```
Ignav 搜价（单程 / 往返）
  → 推荐卡片（中文航线 + 航班号 + rank_reason）
  → 确认选用 / 确认往返
  → travel_intel.flights[]

或：Trip.com 订好
  → 展开「手动添加航段」
  → 填起降时刻 + 航班号
  → 添加航段
```

# 酒店信息 — 获取、比价与落地

← [返回索引](./README.md) · 相关：[00-概述与架构.md](./00-概述与架构.md)

> 分析日期：2026-06-30 · 文档版本：**v1.3**（增补豆包 Trip.com 对话核验）

**落地说明**：与个人开发者一样，酒店**实时库存与全网比价**属于 C 层能力（需商业合作）。Phase 1 仅 deep link + 区域推荐，不做 OTA 库存 API。

---

## 1. 业务目标

- 按 **位置 × 预算 × 评分 × 取消政策** 多维筛选。
- 同一酒店多 OTA 报价对比（含会员价、预付/到店付）。
- 与行程 **区域聚类** 对齐（减少每日跨区通勤）。

---

## 2. 推荐数据源

| 来源 | 优势 | 劣势 |
|------|------|------|
| **Amadeus Hotel API** | 与航班同一账号体系 | 库存因地区而异；SS 将停用 |
| **Expedia Rapid / EPS** | 75 万+ 房源 | 需合作伙伴资质 |
| **Booking.com Affiliate** | 中文友好 | 多为 deep link，非实时库存 API |
| **Hotels.com / Agoda API** | 亚太覆盖好 | 条款与佣金各异 |
| **Google Hotels / TripAdvisor** | 评价聚合 | API 受限，宜作辅助 |
| **Trip.com Affiliate** | 亚太覆盖、个人可申请 | 多为推广链接/Widget；**非**完整库存 API |
| **Trip.com Partner / API 2.0** | 酒店可用性查询（B2B） | 需 `AllianceID`/`SID`/审核；见 [apidoc.trip.com](https://apidoc.trip.com/apidoc) |
| **Apify Trip.com Scraper** | 酒店+景点+火车 MCP 原型 | **爬虫/第三方**，非官方；按量付费 |

### 2.1 数据为何不透明

| 误区 | 实际情况 |
|------|----------|
| Booking 搜一下就有 API | 多数是 Affiliate 跳转 + 佣金，非库存 API |
| Expedia 750 万酒店随便接 | EPS 需 Partner 资质 |
| 同一酒店多平台比价 | 税费、城市税、取消政策展示不一致 |
| LLM 写「¥2000/晚」 | 基本是幻觉或过时信息 |

## 3. 比价 Schema

```typescript
interface HotelQuote {
  id: string;
  name: string;
  lat: number;
  lng: number;
  star_rating?: number;
  guest_rating?: number;      // 如 8.5/10
  check_in: string;
  check_out: string;
  room_type: string;
  occupancy: { adults: number; children: number };
  price_per_night: { amount: number; currency: string };
  total_stay: { amount: number; currency: string; includes_tax: boolean };
  cancellation: 'free_until' | 'non_refundable' | 'partial';
  cancellation_deadline?: string;
  breakfast_included: boolean;
  distance_to_anchor_km?: number;
  source: string;
  fetched_at: string;
}
```

**LLM 职责**：

- 根据 `DayPlan.region` 选 **1 主酒店 + 1 备选**（`is_optional: true`）。
- 解释 trade-off（贵 20% 但步行 5 分钟到地铁）。
- 写入 `category: 'hotel'` 节点，`cost` 用 `per: 'total'` 或 `'group'`。

**阶段 B 修订（2026-07-03）**：主路径改为 **行程倒推住宿片区** → 地图画范围 → 再落 hotel 节点；见 [12-住宿区域倒推方案](./12-阶段B住宿区域倒推方案.md)、[13-实施计划](./13-阶段B住宿区域实施计划.md)。OTA ranked 降为 P5b 可选。

**境外特别注意**：

- **城市税 / 度假村费** 常不含在 OTA 展示价 → `price.note` 必填。
- **押金 / 预授权**。
- 入住 15:00 前存行李、退房时间。
- 亲子：加床、婴儿床政策。

## 4. 落地路线

| 阶段 | 方案 | 说明 |
|------|------|------|
| **Phase 1** | Booking/Agoda **搜索 deep link** | `cost_label: "需自行查询"`；LLM 推荐区域/星级 |
| **Phase 2** | Google Places 评分/地址 | 仍不做 OTA 库存 |
| **Phase 3** | Expedia EPS / Hotelbeds B2B | `HotelQuote[]` + `fetched_at` |
| **Phase 4** | 多 OTA 归一比价 | 若合规且有必要 |

**Schema 映射**：`hotel` 节点 `cost` + 备选 `is_optional` → 见 [00-概述与架构.md §4](./00-概述与架构.md#4-与现有-itinerary-schema-的映射)。

## 5. 豆包对话 Trip.com 数据源核验（2026-06-30）

**来源**：[豆包分享对话 — Trip.com / 携程国际 MCP](https://www.doubao.com/thread/x2b906885bbdb81ce91d412c004cdc7e9)  
**对话主题**：Trip.com（携程国际）MCP / API / Agent 如何接入，覆盖**酒店、景点、火车票**  
**检索词**：`携程国际版 MCP`、`github trip.com mcp server`、`trip.com partner api` 等（28 篇资料）  
**核验方式**：分享页嵌入内容 + [Apify Actor 页](https://apify.com/one-api/trip-com-scraper) + [Trip.com Affiliate](https://www.trip.com/partners/index) + [API 2.0 文档](https://apidoc.trip.com/apidoc)

### 5.1 豆包回复摘要

豆包将方案分为三类：

1. **Apify Trip.com Scraper MCP** — 「唯一现成、10 分钟接入」原型首选  
2. **自行封装** — Affiliate API（个人免费）vs Partner API（商务）  
3. **开源 Agent** — GitHub 无原生 Trip.com 项目，可替换工具层数据源  

选型建议：原型用 Apify；生产用 Amadeus MCP（机票）+ Trip.com 联盟 API 自封 MCP（酒店补充）。

### 5.2 逐条真伪核验（酒店相关）

| 豆包说法 | 核实结果 | 结论 |
|----------|----------|------|
| Apify `one-api/trip-com-scraper` MCP 存在 | [Actor 页](https://apify.com/one-api/trip-com-scraper) 确认；支持 MCP Standby | ✅ 项目真实 |
| 「唯一现成 Trip.com MCP」 | 另有 [trip-com-hotels-scraper](https://apify.com/shahidirfan/trip-com-hotels-scraper)、RollingGo 酒店 MCP 等 | ⚠️ **夸大** |
| 覆盖酒店搜索、详情、价格 | Actor README 确认酒店 autocomplete/search/detail | ✅ |
| 免费档 $5 ≈ 5000–10000 条 | 定价 **$3/1000 results**（按事件计费）；$5 额度约 **1600 条量级**，非 1 万 | ⚠️ **数量算错** |
| 底层 Trip.com 官方 API | 经 **realtyapi.io / 爬虫** 聚合，非 Trip.com 直连 | ⚠️ **本质说轻了** |
| 「10 分钟接入、适合商用」 | 社区 Actor 仅 18 用户；爬虫有 ToS/失效风险 | ❌ **商用不可信** |
| Affiliate 个人可免费申请 | [Affiliate Program](https://www.trip.com/partners/index) 个人/无网站也可申请 | ✅ |
| Affiliate = 基础价格查询 API | 联盟主要是 **链接/Widget/佣金**；实时库存 API 2.0 需 Partner `aid/sid/token` | ⚠️ **混淆两层** |
| Partner API 需商务、可预订闭环 | 与 [developers.trip.com](https://developers.trip.com/) / API 2.0 文档一致 | ✅ |
| GitHub 无原生 Trip.com 旅行 Agent | 检索未见成熟「Trip.com 内置数据」Agent；多为 Amadeus/模拟工具 | ✅ 大体正确 |
| 生产机票用 Amadeus 官方 MCP | Amadeus Self-Service **2026-07-17 停用** | ⚠️ 见 [01-航班信息.md §5](./01-航班信息.md#5-豆包对话航班信息核验2026-06-30) |

**统计（酒店主线）**：✅ 4 · ⚠️ 5 · ❌ 1 — **比航班那篇略靠谱，但仍混用联盟/Partner/爬虫三层。**

### 5.3 对本项目酒店落地的修正建议

| 优先级 | 方案 | 说明 |
|--------|------|------|
| **P0** | Trip.com / Booking **Affiliate deep link** | 与 Phase 1 一致；展示佣金披露 |
| **P1（原型）** | Apify Scraper MCP | 仅内部验证；`confidence: medium` + 爬虫免责声明 |
| **P2（合规）** | 申请 Trip.com Affiliate → 若需结构化价再谈 Partner API 2.0 | 非「注册即得库存 API」 |
| **避免** | 把 Apify 当生产核心、按豆包「1 万条免费」估成本 | 定价与合规均不成立 |

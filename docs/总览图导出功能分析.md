## 1. 功能目标

总览图导出是旅行规划的**分享/存档**场景：PNG **与屏显一致**（暗色实色）、全列全节点、连线可读；导出过程中屏显仍可辨认行程，不整区空白。

**产品决策（已确认）**：

- 仅 PNG，无 PDF
- 导出图内**不加**独立行程标题/日期范围页眉（列头 Day 信息保留）
- 单日图导出**不含**图例（仅截 `data-export-day-graph` canvas）
- 总览图导出**含**线型图例
- **P121**：导出所见即所得（暗色）；OV-02 浅底主题暂缓（浅色/遮罩曾导致闪白、空屏、错图）

## 2. 当前实现架构

```
ExportGraphButton.handleExport()
  ├─ overview
  │    ├─ setExportOverviewCapture(true)      // 关虚拟化；暗色实色
  │    ├─ waitForOverviewExportReady()
  │    └─ exportOverviewShell()
  │         ├─ data-exporting（无 light theme）
  │         ├─ 解除 max-height + 实测矩阵高度
  │         └─ captureElementPng(width, height)
  │              ├─ pickExportPixelRatio
  │              ├─ 大面积 skipFonts / 字体超时
  │              └─ toPng bg #070b10 + 45s 超时
  └─ day
       └─ exportElementToPng([data-export-day-graph])
```

### 导出捕获范围

| 模式 | 截图根节点 | 含图例 | 主题 |
|------|-----------|--------|------|
| 总览 | `[data-export-overview]` overview-shell | ✅ | dark（同屏显） |
| 单日 | `[data-export-day-graph]` ReactFlow canvas | ❌ | dark |

## 3. 已修复问题 ✅

| 问题 | 根因 | 修复 |
|------|------|------|
| 底部截断 | `max-height: 100%` | 导出时解除 + 实测高度 |
| 连线黑色块 | SVG `fill` / `color-mix` | inline 实色 + `fill="none"` |
| 区域底色偏色 | `color-mix` 克隆失效 | 导出态暗色实色 tokens |
| 列宽漂移 | 未传 `overviewColumnWidths` | 已传入 |
| 间歇缺列 | 虚拟化未挂满 | `waitForOverviewExportReady` |
| 交互态渗入 | 高亮/幽灵/resizer | `exportOverviewCapture` |
| **导出白屏/空屏（P121）** | **浅色主题；veil 盖死；park reparent** | **暗色所见即所得；禁止遮罩/挪节点** |
| **导出图不对** | **light 主题与节点/边色冲突；遮罩期错捕** | **暗色底 + 显式宽高 + 自适应 ratio** |
| **导出纵向截断（P121）** | **`flex:1; min-height:0` 把壳压回视口，foreignObject 只绘可视条带** | **导出态 `flex:0 0 auto` + minHeight=内容高；按 scrollHeight 捕获** |
| **节点卡片样式错乱（P121）** | **`color-mix`/CSS 变量/入场动画/跳过字体 → foreignObject 布局崩** | **导出态实色 inline + 关动画 + 系统 CJK 字体栈** |

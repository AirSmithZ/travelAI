## 1. 功能目标

总览图导出是旅行规划的**分享/存档**场景：PNG 与屏显一致、全列全节点、连线可读。

**产品决策（已确认）**：

- 仅 PNG，无 PDF
- 导出图内**不加**独立行程标题/日期范围页眉（列头 Day 信息保留）
- 单日图导出**不含**图例（仅截 `data-export-day-graph` canvas）
- 总览图导出**含**线型图例

---

## 2. 当前实现架构

```
ExportGraphButton.handleExport()
  ├─ overview
  │    ├─ setExportOverviewCapture(true)
  │    ├─ waitForOverviewExportReady()
  │    └─ exportOverviewShell()
  │         ├─ 解除 max-height 限制 + 实测矩阵高度
  │         ├─ data-exporting + solid 色 / SVG inline 属性
  │         └─ toPng (pixelRatio:2, fontEmbedCSS)
  └─ day
       └─ exportElementToPng([data-export-day-graph])  // 不含 legend / lane-header
```

### 导出捕获范围

| 模式 | 截图根节点 | 含图例 |
|------|-----------|--------|
| 总览 | `[data-export-overview]` overview-shell | ✅ 线型图例 |
| 单日 | `[data-export-day-graph]` ReactFlow canvas | ❌ |

## 3. 已修复问题 ✅

| 问题 | 根因 | 修复 |
|------|------|------|
| 底部截断 | `overview-shell { max-height: 100% }` 限制视口高度 | 导出时 `max-height: none` + 实测 `matrix` 高度 |
| 连线黑色畸变块 | SVG path 默认 `fill: black`，`color-mix` stroke 未克隆 | `fill="none"` + inline `stroke` 实色 |
| 区域底色偏色 | `color-mix` 在 html-to-image 中失效 | `isExporting` 时用 `overviewExportTokens` 实色 |
| 列宽漂移 | 导出 layout 未传 `overviewColumnWidths` | 已传入 |
| 间歇缺列 | 虚拟化关闭后渲染未完成 | `waitForOverviewExportReady` 轮询 |
| 交互态渗入 | 高亮/选中/幽灵/resizer | `exportOverviewCapture` + `data-exporting` |
| 单元格高度不足 | 连线端点未计入 `maxY` | `computeCellLayout` 纳入 edge 坐标 |

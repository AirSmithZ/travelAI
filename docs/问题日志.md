### P112 · 店名搜索顶层独立 + 地图分层（2026-08-09）✅

**现象**：店名搜索仍嵌在各确认片区卡片内；锁定走 `addHotelFromZone` 强制绑 `zone_id`；切换选中片区会替换/清空店名搜索地图钉。

**确认规则**
1. 店名搜索锁定**不绑定** `zone_id`，地图仅作独立层展示
2. 片区附近钉：仅**当前选中**片区
3. 切换片区**不得重置**店名搜索标记

**修复**
- 布局：`偏好 → 店名搜索（顶层）→ 推荐片区（仅片区附近）→ 已锁定酒店（公共）`
- 新增 `addStandaloneHotel` / `hotelFromStandaloneInput`（无 `zone_id`）
- 地图钉合成：`nameResults`（全局持久）∪ `areaResults[selectedStayZoneId]` ∪ `intel.hotels`

**主键**：`StayZonePanel.tsx` · `ZoneHotelNameSearchModule.tsx` · `usePlanStore.ts` · `hotelIntelSync.ts`

### P108 · 角标有候选但全球底图无酒店钉（2026-08-09）✅

**现象**：选酒店后角标「住宿预览 · 8 家候选」，右侧为全球视野、无片区圈/候选钉。

**根因**
1. `PreviewPane` 用 Framer Motion `opacity:0→1` 包裹 `TravelMap`，MapLibre 在透明父级下自定义层/镜头易失效
2. 酒店钉走 GeoJSON circle 层，style/尺寸竞态下 `setData` 后仍可能不上屏
3. fit 若混入近 (0,0) 或超大 bounds，镜头被拉成全球视图

**修复**
- 住宿预览地图改为无动画普通 `div` 挂载
- 酒店候选改为 **DOM Marker**（点+店名）
- `isValidMapCoord` 过滤 null-island；超大 bounds 回退到选中店 `easeTo`
- style `load` 后 `jumpTo` 新加坡并挂起 stay fit

**主键**：`PreviewPane.tsx` · `stayHotelMapPins.ts` · `TravelMap.tsx` · `mapCoordGuards.ts`

### P107 · 骨架 / 偏好 / 酒店钉不上图（2026-08-09）✅

**现象**
1. 「推荐中…」骨架仅两道空心细条，对比度不足，不像片区卡
2. 偏好区用原生 checkbox，观感廉价；用户怀疑未接入逻辑

### P96 · parse 未关 thinking 导致空 content（2026-08-09）✅

**现象**：对话 parse SSE 出现 `validate/fixing` 后报错「请增大 LLM_MAX_TOKENS_GENERATE」；reasoning 实为抽表单/patches，非行程生成。日志：`parse_stream … finish_reason=length completion_tokens=2500 content_chars=0`。

**根因**：P93 只给 **generate** 关了 `thinking`；`chat_parse` 仍默认开启，reasoning 吃光 `LLM_MAX_TOKENS_PARSE`；空 content 文案写死 GENERATE 造成误诊。与 P94/P95 无关。

**修复**：parse / parse_stream / parse_fix* 一律 `thinking=False`；空 content 按 endpoint 提示 `LLM_MAX_TOKENS_PARSE` 或 `GENERATE`。

**主键文件**：`chat_parse.py` · `llm_client.py`

### P84 · 松手后实线错位、滚动才对齐（2026-08-09）✅

### P61–P66 · 地理编码 autocomplete 专项（2026-06-29）✅

**原现象**：`GET /geocode/autocomplete?q=哥打基纳巴卢国际机场&city=亚庇` → `{"results":[]}`。

**根因**

1. 仅 Nominatim 单源，当前环境 **403 Forbidden**
2. Photon 未带 **User-Agent** 时同样 403（httpx 默认 UA 被拒）
3. 异常被 `return []` 吞掉，HTTP 200 误导前端
4. `city=亚庇` 无英文别名归一
5. 前端需手动点按钮，无 debounce 联想

**修复**

| # | 要点 | 文件 |
|---|------|------|
| P61 | Provider 链 `photon,nominatim` 回退；Photon/Nominatim 均带 `GEOCODE_USER_AGENT` | `geocode_providers.py`, `config.py` |
| P62 | 全源失败 → `502` + `GeocodeProviderError`；真无结果 → `warnings` | `geocode.py`, `geocode_providers.py` |
| P63 | `GeocodeProvider` 抽象 + `GEOCODE_PROVIDERS` / `PHOTON_BASE_URL` / `NOMINATIM_BASE_URL` | `geocode_providers.py`, `config.py` |
| P64 | `city_aliases.py`：`亚庇` → `Kota Kinabalu, Malaysia`；多 query 变体 | `city_aliases.py`, `geocoding.py` |
| P65 | `NodeCoordEditor` 输入 debounce 400ms 自动联想 + 候选列表 | `NodeCoordEditor.tsx` |
| P66 | `GeocodeApiError` 展示上游 502；空结果区分 `warnings` vs 服务失败 | `geocode.ts`, `NodeCoordEditor.tsx` |

**响应扩展**

```json
{
  "results": [...],
  "provider": "photon",
  "warnings": []
}
```

**验收**

```bash
# 后端实测（2026-06-29）
geocode_autocomplete('哥打基纳巴卢国际机场', '亚庇') → provider=photon, count≥1
npm run build ✅
```

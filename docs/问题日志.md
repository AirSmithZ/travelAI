## 已关闭

### P61–P66 · 地理编码 autocomplete 专项（2026-06-29）✅

**原现象**：`GET /geocode/autocomplete?q=哥打基纳巴卢国际机场&city=亚庇` → `{"results":[]}`。

**根因**

1. 仅 Nominatim 单源，当前环境 **403 Forbidden**
2. Photon 未带 **User-Agent** 时同样 403（httpx 默认 UA 被拒）
3. 异常被 `return []` 吞掉，HTTP 200 误导前端
4. `city=亚庇` 无英文别名归一
5. 前端需手动点按钮，无 debounce 联想

**修复**

| # | 要点 | 文件 |
|---|------|------|
| P61 | Provider 链 `photon,nominatim` 回退；Photon/Nominatim 均带 `GEOCODE_USER_AGENT` | `geocode_providers.py`, `config.py` |
| P62 | 全源失败 → `502` + `GeocodeProviderError`；真无结果 → `warnings` | `geocode.py`, `geocode_providers.py` |
| P63 | `GeocodeProvider` 抽象 + `GEOCODE_PROVIDERS` / `PHOTON_BASE_URL` / `NOMINATIM_BASE_URL` | `geocode_providers.py`, `config.py` |
| P64 | `city_aliases.py`：`亚庇` → `Kota Kinabalu, Malaysia`；多 query 变体 | `city_aliases.py`, `geocoding.py` |
| P65 | `NodeCoordEditor` 输入 debounce 400ms 自动联想 + 候选列表 | `NodeCoordEditor.tsx` |
| P66 | `GeocodeApiError` 展示上游 502；空结果区分 `warnings` vs 服务失败 | `geocode.ts`, `NodeCoordEditor.tsx` |

**响应扩展**

```json
{
  "results": [...],
  "provider": "photon",
  "warnings": []
}
```

**验收**

```bash
# 后端实测（2026-06-29）
geocode_autocomplete('哥打基纳巴卢国际机场', '亚庇') → provider=photon, count≥1
npm run build ✅
```

**配置（可选 `.env`）**

```bash

GEOCODE_USER_AGENT=TravelPlanner/0.2 (your-contact-url)
```
